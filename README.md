## The line

> The meeting that could have been an email became the email that could have been nothing — and is now another meeting.

117 characters, one sentence. The program writes it to `/output/entry.txt`:

```sh
node main.ts
```

## Why this line

The judge weighs a real surprise at the end that still makes sense, an everyday truth people recognise, and economy of words. Everyone has sat in the meeting that should have been an email; the line escalates that truth one step further (email → nothing) and then snaps it back (nothing → another meeting). No setup, no explanation, nothing to trim.
